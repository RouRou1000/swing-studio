## Swing Studio

Got bored of the same swing animation every time, so I made this. You can change how any item swings in first person: swords, axes, totems, whatever you're holding.

Press **K** in game and the editor opens. Your hand updates live while you change stuff, so you see right away what it does.

### What you can change

- Speed and timing curve
- Swing type (slash, chop, stab, uppercut...)
- Direction, also alternating like a combo
- Extra rotation, flips and spins
- How the item is held (position, angle, size)

There are 63 presets if you don't want to set everything yourself. You can use one setup for all items or give single items their own. Setups can be saved and shared with a code.

### Info

Client-side only, so it works on any server. Needs [Fabric API](https://modrinth.com/mod/fabric-api). Made for Minecraft 26.3.
